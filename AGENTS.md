# Agent Rules

- Describe product problems in user-visible UI language (screen / panel / button / badge / state the naked eye can see), not in code-file terms. No file paths, line numbers, function names, or schema field names unless the user explicitly asks for code.
- Never use PRD / internal requirement IDs in user-facing answers. Translate every item into the screen and control the user can actually see and click.
- Every UI problem must name the visible screen name plus its URL hash route so the user knows exactly where to look.
